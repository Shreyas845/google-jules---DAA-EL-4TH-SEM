# Research Archive (historical)

This folder preserves the **raw research process** behind ISL (Incremental
Significance-Leiden). It is kept for provenance and defense of the research, but it is
**not** the current specification of the project.

For what the project *is today*, see:

- Top-level [`README.md`](../../README.md) — install & run workflow
- [`../final_master_blueprint.md`](../final_master_blueprint.md) and
  [`../final_master_blueprint_part2.md`](../final_master_blueprint_part2.md) — the canonical
  algorithm/experiment design

## Contents

| File | What it is |
|------|-----------|
| `PROJECT_MASTER_BRIEF.md.txt` | Original consolidated project brief |
| `O1.txt`, `O2.txt`, `O3.txt` | Early research notes / literature positioning / methodology exploration |
| `sonnet review 2.txt` | An external design-review pass on the methodology |

> Note on terminology: early notes discuss the project under the working name
> **"Incremental Surprise-Leiden"** and use the **Surprise** objective. The project later
> settled on the **Significance** objective, and the final identity is
> **ISL — Incremental Significance-Leiden**. Where these notes say "Surprise", read it as the
> historical objective that was superseded by Significance.
